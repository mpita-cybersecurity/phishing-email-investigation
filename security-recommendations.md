# Security Recommendations

## Purpose

This document provides recommended actions for preventing and responding to the simulated phishing email investigated in this project.

## Recommended Actions for Employees

1. Do not click suspicious links in unexpected emails.
2. Do not provide passwords, banking information or personal information through suspicious emails.
3. Verify unexpected requests through an independently trusted communication channel.
4. Report suspected phishing emails to the appropriate IT or security team.
5. Avoid replying to suspicious emails.
6. If a suspicious link has already been opened or information has been submitted, report the incident immediately.

## Recommended Organisational Controls

Organisations can reduce phishing risk through:

* Security awareness training
* Multi-factor authentication (MFA)
* Email filtering and anti-phishing controls
* Endpoint protection
* Regular security awareness exercises
* Strong password policies
* Monitoring and logging
* Incident reporting procedures

## Incident Response

If an employee interacts with a suspected phishing message, the organisation should follow its incident response procedures.

Potential actions may include:

1. Reporting the incident.
2. Securing the affected account.
3. Resetting compromised credentials.
4. Reviewing authentication and security logs.
5. Investigating related activity.
6. Blocking confirmed malicious indicators where appropriate.
7. Documenting the incident and lessons learned.

## Conclusion

Phishing attacks combine technical methods with social engineering. Technical security controls are important, but employees also need to understand how to recognise suspicious communication and report it quickly.
